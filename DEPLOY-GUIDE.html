Step 1 — GitHub (5 minutes)

Create a GitHub Repository

GitHub stores your site files. Vercel watches GitHub — every time you update a file, your site automatically redeploys in seconds. This is how professional sites are managed.

1
Create a free GitHub account
Visit github.com and sign up with your email address. It's completely free.
→ github.com/join
2
Create a new repository
Click the green "New" button on your GitHub dashboard. Set the repository name to yachtharbours. Set visibility to Public. Click "Create repository".
3
Upload your 6 files
On the new repository page, click "uploading an existing file" (you'll see this link in the middle of the page). Drag all 6 files from your yachtharbours folder into the upload area. Scroll down and click "Commit changes".
ℹ️
Why GitHub? When your domain launches or you want to update the site, you just drag a new file to GitHub and your site automatically updates worldwide within 30 seconds.
Step 2 — Vercel (10 minutes)

Deploy to Vercel

Vercel hosts your site globally on their CDN network. Free tier is more than sufficient — and it auto-deploys every time you push to GitHub.

1
Create a Vercel account
Go to vercel.com and click "Sign Up". Choose "Continue with GitHub" — this links your accounts automatically.
→ vercel.com/signup
2
Import your GitHub repository
From your Vercel dashboard, click "Add New… → Project". You'll see your GitHub repositories listed. Click "Import" next to yachtharbours.
3
Configure deployment settings
On the configuration screen, set these values:
Vercel Settings
Framework Preset: Other
Root Directory: ./ (leave as default)
Build Command: (leave empty)
Output Directory: ./ (leave as default)
Install Command: (leave empty)
Click "Deploy". Vercel will build and deploy your site in about 30 seconds.
4
Your site is now live on a Vercel URL
Vercel will give you a URL like yacht-harbours.vercel.app. Open it and confirm everything looks correct. This is your site — working! Next we connect your real domain.
⚡
Alternative (no GitHub needed): In Vercel, click "Add New → Project → Upload" and drag your entire folder. Quicker but you lose the auto-deploy feature.
Step 3 — Cloudflare (5 minutes)

Add Domain to Cloudflare

Cloudflare gives you free SSL, free DDoS protection, and the world's fastest DNS — all in one step. This is the most important setup step.

1
Create a free Cloudflare account
→ dash.cloudflare.com/sign-up
2
Add your site
In the Cloudflare dashboard, click "Add a Site". Type yachtharbours.com and click "Add Site". Select the Free plan and click "Continue".
3
Note your Cloudflare nameservers
Cloudflare will show you two nameservers. They look like this — yours will be slightly different:
Nameserver 1: aria.ns.cloudflare.com
Nameserver 2: bob.ns.cloudflare.com
Copy both nameservers. You'll need them in the next step.
Step 4 — Domain Registrar (5 minutes)

Point Domain to Cloudflare

Log into wherever you bought yachtharbours.com and replace the default nameservers with Cloudflare's. This tells the internet to route your domain through Cloudflare.

⏳ When to do this step

Only do this once your domain is released and active. If you registered it and it's still "pending" — wait until you receive confirmation that it's live before changing nameservers.

1
Log into your domain registrar
Go to the website where you bought yachtharbours.com. Find the DNS or Nameserver settings for the domain.
2
Replace the nameservers
Delete any existing nameservers and add your two Cloudflare nameservers from Step 3. Save the changes.
3
Add DNS records in Cloudflare
Back in Cloudflare → DNS → Records. Add these two records pointing to Vercel:
TypeNameValueProxy
A@76.76.21.21☁️ Proxied (orange)
CNAMEwwwcname.vercel-dns.com☁️ Proxied (orange)
ℹ️
Proxied (orange cloud) is important. It routes traffic through Cloudflare's network, activating DDoS protection, SSL, and CDN automatically.
4
Add domain in Vercel
In Vercel → your project → Settings → Domains. Click "Add" and type www.yachtharbours.com. Vercel will verify the DNS automatically (usually within 5 minutes).
⏱️
Propagation time: DNS changes can take between 5 minutes and 48 hours to work globally. Usually it's under 30 minutes. You can check propagation at dnschecker.org.
Step 5 — SSL & Security (5 minutes)

Enable SSL & Security

Turn on these Cloudflare settings. All free. All critical. Takes about 5 minutes to click through.

🔒 SSL/TLS Settings

In Cloudflare → SSL/TLS → Overview

Set encryption mode to: Full (Strict)

⚡ Edge Certificates — turn ALL of these ON

In Cloudflare → SSL/TLS → Edge Certificates

  • ✅ Always Use HTTPS — redirects all HTTP → HTTPS automatically
  • ✅ Automatic HTTPS Rewrites — fixes mixed content warnings
  • ✅ HTTP Strict Transport Security (HSTS) → Max Age: 6 months, Include Subdomains: On, Preload: On
  • ✅ TLS 1.3 — latest encryption standard

🛡️ Security Settings

In Cloudflare → Security → Settings

  • ✅ Security Level: Medium
  • ✅ Bot Fight Mode — blocks automated scrapers
  • ✅ Browser Integrity Check

🚀 Performance Settings

In Cloudflare → Speed → Optimization

  • ✅ Auto Minify — HTML ✓ CSS ✓ JavaScript ✓
  • ✅ Brotli Compression
  • ✅ HTTP/3 (QUIC) — fastest protocol
